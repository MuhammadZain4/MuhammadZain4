# 💫 About Me

Hi, I'm **Muhammad Zain** 👋

Data Science undergraduate at the University of Central Punjab (UCP), Lahore, building practical AI and data-driven applications with a focus on backend systems, LLMs, and automation.

## 🚀 What I Do

- Build production-style **REST APIs** with FastAPI and SQL Server
- Develop **RAG pipelines** and **multi-agent LLM applications** using LangChain and LangGraph
- Design **AI automation workflows** with n8n and Docker
- Work on end-to-end data applications, from database design to deployment

## 🛠️ Core Skills

- **Languages:** Python, SQL
- **Backend:** FastAPI, JWT Authentication, Stored Procedures
- **AI/ML:** LangChain, LangGraph, RAG, NLP, Deep Learning
- **Databases:** SQL Server, PostgreSQL
- **Tools:** Docker, n8n, Streamlit, Git

## 📌 Featured Work

- **Document Q&A (RAG) Assistant:** FastAPI + SQL Server
- **MedAssist AI:** LangGraph multi-agent clinical decision support system
- **Invoice Automation Pipeline:** LLM-based extraction with n8n, SQL Server, and email notifications
- **Pakistan Finance RAG System:** Final Year Project

## 💼 Experience
